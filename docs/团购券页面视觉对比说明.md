# 团购券页面视觉对比说明

本文保留团购券页面与参考图之间的信息层级对比，不记录开发阶段。参考图只用于检查结构、比例、密度和交互位置，不复制第三方品牌、素材、字体、颜色或文案。

## 检查范围

- 商品详情：封面、标题、价格、销量、门店、购买须知和购买入口。
- 购买须知：有效期、使用时间、使用规则、预约/叠加/退款规则。
- 确认订单：数量、原价、优惠、实付、库存和提交操作。
- 订单与券包：状态标签、退款入口、二维码和客服入口。

## 视觉约束

- 使用 Roamly 主题色和 TDesign 组件，不引入竞品 Logo 或默认蓝色。
- 常见手机宽度检查文字溢出、底部栏遮挡、按钮错位和内容跳动。
- 空态、加载、错误和弱网状态必须保留真实反馈。
- 页面显示服务端状态和金额，不能以视觉动画替代业务事实。
